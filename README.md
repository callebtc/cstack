# cstack

A collection of my skills and workflows for productive agentic engineering.

## Skills

- **[external-review-loop](skills/external-review-loop/SKILL.md)** — Runs an iterative PR review loop using an external CLI reviewer (Codex, Claude Code, or Antigravity/Gemini) on a clean checkout of the PR head. The coding agent investigates each finding, fixes and verifies agreed issues, pushes scoped commits, and requests follow-up rounds until the PR is clean.
